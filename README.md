# Dear Ekra — Official Creator Portfolio

A high-converting, modern creator portfolio website for **Dear Ekra (Rukaiya Binta Hossain)** — Dhaka's leading Lifestyle, Food, Beauty, and Travel storytelling creator.

## Features

- **Dynamic Hero Section**: Real metric counters (2.4M+ Top Reel, 16K+ Followers, 593+ Reels, 12.8M+ Total Views) and an interactive 8-look portrait showcase with auto-cycling.
- **Capsule Sticky Header**: Floating luxury bar with interactive heartbeat, smooth section navigation, social icons, and quick-contact drawer.
- **Curated Kinetic Statement**: Fluid scroll-reactive typography powered by Motion.
- **Verified Video Reel Gallery**: Category-filtered gallery (Food & Cafe Reviews, Beauty & Skincare, Fashion & Styling, Travel & Staycations, Campus Life & Tech) with in-site autoplay previews and fullscreen Facebook reel playback.
- **3 Working Principles & Brand Marquee**: Editorial standards showcase paired with an infinite, seamless brand ticker featuring verified client partners.
- **How We Work**: 3-step collaboration roadmap with embedded studio preview reel.
- **Direct 1-Tap Connect**: Zero-friction message sender directly routing to WhatsApp, Messenger, and Gmail.
- **Cinematic Footer**: Custom full-width Dear Ekra composite artwork with Back-to-Top action.
- **Creator Admin Hub**: Built-in drawer (`#admin`) with local storage persistence to add, edit, or remove campaign reels on the go.

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
```
Generates production-ready bundled assets into the `dist/` directory.

### Preview Production Build
```bash
npm run preview
```

## Tech Stack
- **Framework**: React 18
- **Bundler & Dev Server**: Vite 6
- **Styling**: Tailwind CSS 3
- **Animations**: Motion (Framer Motion v12)
- **Icons**: Lucide React
